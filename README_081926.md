# Warming Reduces Cold Hardiness of Boreal Plants but Damage Risk Varies by Species and Season

Code and data used to analyze how whole ecosystem warming affects bud cold hardiness of boreal overstory and understory species at the SPRUCE experiment. 

##Analysis

The folder contains:

## Data files

- All_SPR_032826.csv: cold hardiness data, with Species, Collection, Date, Season, Treatment, Plot, deacclimation days (deacc.days), and LTE (low temperature exotherm = cold hardiness measurements).
- SPR_weather_data_042526_v2.csv: overstory (2 m) weather data, with hourly Temp by Treatment, Plot, and Season; used for corrected plot temperature (ΔT) calculations.
- SPR_weather_data_042526_TS_0_avg.csv: understory (0 m) weather data, same structure as the 2 m file, used for the understory species.
- Control_Freeze_SPR_051326.csv: Cold hardiness data for the control freeze test data used for Figure S1.

##Analysis file

- Exp_CH_081926.Rmd: analysis and figure preparation code.
    Species codes
        Overstory (2 m): LALA (Larix laricina), PIMA (Picea mariana)
        Understory (0 m): CHCA (Chamaedaphne calyculata), RHGR (Rhododendron groenlandicum)

##How to run the analysis
1. All analysis and data files should be in the same folder (update the file paths in the import chunks to match your local folder).
2. Open the .Rmd file and run the packages chunk first, then the data import and temperature correction chunks.
3. Steps within the analysis are annotated in the code.
4. Figures are created individually; the slope comparison test (per-species, per-season) is at the end.
